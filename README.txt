RAM MOVERS PREMIUM WEBSITE

FILES
- index.html
- style.css
- script.js

HOW TO USE
1. Upload all three files to the same folder on GitHub.
2. Open repository Settings.
3. Go to Pages.
4. Choose "Deploy from a branch".
5. Select main branch and root folder.
6. Save.

IMPORTANT BEFORE PUBLISHING
